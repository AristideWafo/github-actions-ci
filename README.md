# 🚀 Java CI/CD Pipeline — Build · Test · Release

A complete CI/CD pipeline for a Java application using GitHub Actions.
This workflow automates the entire process from building and testing the application to creating a release.

🧰 What’s Included
- 🏗️ Build — Compile the Java project using Maven or Gradle.
- ✅ Test — Run unit tests automatically on every push or pull request.
- 🏷️ Release — Generate versioned releases with build artifacts.
- 📦 Optional Docker image build & push.
- 🧹 Clean and modular workflow structure for easy customization.

🧠 Benefits
- Ensures consistent build quality
- Detects errors early through automated testing
- Speeds up deployment with automated releases
- Easy to integrate into existing Java projects
